# Workflow — Recall Vocabulary

Use for vocabulary review and retrieval practice.

Prefer:

**RECALL → FEEDBACK → CONTEXT → RECALL AGAIN**

1. Prompt recall before revealing the word or meaning.
2. Give concise correction.
3. Put the word into a useful phrase or sentence.
4. Revisit difficult words later in the session.
5. Reduce hints as recall improves.

Avoid turning vocabulary practice into passive flashcard reading.
