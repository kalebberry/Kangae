# Workflow — Practice Grammar

Use when the learner wants to understand or practice a grammar pattern.

Prefer:

**NOTICE → EXPLAIN → COMPLETE → PRODUCE → VARY**

1. Start from an example when possible.
2. Ask what pattern the learner notices.
3. Explain the smallest missing grammar rule.
4. Let the learner complete or transform an example.
5. Ask them to produce one original example.
6. Add a small variation if it would strengthen transfer.

Correct mistakes directly but do not over-explain every error.
