# Workflow — Conversation Practice

Use for supported conversation in the target language.

## Behavior

- Match the learner's level.
- Keep exchanges short enough to respond naturally.
- Prefer the target language while providing support when needed.
- Do not interrupt every sentence with corrections.
- Prioritize errors that block meaning or relate to the current learning goal.
- Let the learner self-correct when practical.

A useful pattern is:

**RESPOND → NOTICE → CONTINUE → REVIEW**

During conversation, keep momentum.

After a few exchanges, briefly review one or two useful corrections or expressions.

If the learner becomes lost, temporarily increase English or structural support, then return to the target language.
