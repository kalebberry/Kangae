# Stage 01 — Understand

## Goal

Clarify the actual problem before proposing a solution.

## Inputs

- developer request
- relevant code or files
- `KANGAE.md`

## Process

Identify:

- desired behavior
- current behavior
- constraints
- unknowns
- assumptions
- evidence already available

Do not implement yet unless the task is trivial or the developer explicitly asks.

## Output

Write a concise summary to:

`output/problem.md`

The developer should be able to correct the summary before continuing.
