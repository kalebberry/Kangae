# Stage 05 — Review

## Goal

Evaluate the current solution, reasoning, and tradeoffs.

## Process

Review for:

- correctness
- bugs
- accessibility
- security
- performance
- maintainability
- architectural fit
- tradeoffs
- stylistic preferences

Clearly distinguish defects from preferences.

AI review is a second opinion. The developer decides whether a finding is valid.

## Output

Write the review to:

`output/review.md`
