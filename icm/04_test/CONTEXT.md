# Stage 04 — Test

## Goal

Validate ideas with evidence.

## Process

Prefer:

**OBSERVE → HYPOTHESIZE → PREDICT → TEST**

Use evidence such as:

- DevTools
- logs
- tests
- runtime behavior
- documentation
- minimal reproductions
- source code

Do not patch the symptom before understanding what the result tells us.

Record:

- what was tested
- expected result
- actual result
- what the evidence supports
- what the evidence rules out

## Output

Write findings to:

`output/evidence.md`
